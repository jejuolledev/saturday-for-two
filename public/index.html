Type what each of you loves. The agent asks Qloo's taste graph where your two tastes actually meet, and plans a day around that. When nothing meets, it says so and you take turns.

        How it works

        1. Find each favourite in Qloo. Each name goes to /search. If the first match has no taste data, the agent tries the next one and tells you.
        2. Get each person's own list for every part of the day with /v2/insights, using their age band if given: top 100 places in your city that are open on Saturday (no bars if someone under 18 is coming), top 200 films, artists and shows (rated for who is coming).
        3. Find where the lists meet. A pick is only called shared if it is in both people's own lists, and the agent prefers the one whose worse rank is best. Each candidate is scored for each person with filter.results.entities. Mixing everyone's likes into one call is not enough: one person's taste usually drowns out the other, and the plan shows you what that call would have picked.
        4. Show the evidence. Every pick shows its rank in each person's own list, Qloo's English description and its Qloo tags. The full log of Qloo calls is one click away.
        5. Be honest. If nothing is in both lists, the plan says so and you take turns: from each person's top 10, the pick the other person minds least.

        No language model writes this plan, so it cannot invent a place or a film: every pick is a Qloo entity. Results describe what people with similar tastes tend to like; they are not a promise about any one person.
